# 网页使用与部署

AsterCite 提供论文问答工作台：左侧浏览论文，中间提问并查看 Agent 执行过程，右侧阅读原始 PDF 和引用原文。

回答以论文题目标识文章。问答会区分任务进行中、已回答、部分完成和等待补充信息。需要继续处理时，Agent 会结合实际工具结果接着执行；无法继续时会保留已有回答，并说明还缺什么。普通文本回答同样可用。

“记忆”窗口分为当前会话和长期记忆。长期记忆使用本地 Qdrant Edge 与现有 BGE-M3，保存明确的长期回答偏好、主动要求记住的笔记，以及按论文合并的阅读进度、要点和待解决问题；同一浏览器新建对话时可按问题找回。可以查看、添加、修改、删除、暂停记忆，也可手动整理当前会话的偏好和阅读进度。阅读记忆在现有请求额度内进行简短提炼，整理失败时保留简短进度，不影响回答；手动修改的条目优先保留。回答下方会显示本轮实际读取的长期记忆。

每个浏览器使用独立的记忆身份，身份保存在浏览器中，记忆正文保存在运行服务的设备上；清除浏览器存储后不能自动找回该身份。删除对话会同时清理来自该对话的自动记忆。阅读摘记用于接续讨论，论文结论仍须查阅原文。记忆文件位于 `.local/memory/`，不包含在源码和安装包中。

回答中的引用数量取决于实际用到的原文，没有五条的总上限。完整问答每次默认取八个片段，需要时可增加到二十个，并继续读取后续片段或补查缺项。

询问论文的表格或公式时，工作台会尝试读取该论文公开的结构化原文，保留表头、单位、数值和数学表达，显示为表格与公式；长表按完整行分组读取。原文依据默认显示英文，点击“翻译为中文”才请求译文，也能打开对应的原文位置。首次读取需要联网，之后使用本机阅读缓存；只有 PDF 或结构无法恢复时，会说明缺少的内容，可以继续在右侧阅读 PDF。

## 查看示例

```powershell
npm ci --ignore-scripts
npm run web
```

打开 `http://127.0.0.1:4173`。默认回放示例对话，不需要模型配置或检索环境。在线演示站使用相同的网页。

## 完整问答

Windows 用户可以直接使用 [安装版](windows.md)，安装后填写自己的模型设置，启动本机网页问答。

先按 [安装指南](environment.md) 准备论文库、模型和索引，再按 [配置指南](configuration.md) 填写 `configs/model.local.json`，并在终端设置自己的 `PIPAPER_API_KEY`。

```powershell
npm run doctor
npm run web -- --live
```

启动时会加载本地检索模型。准备就绪后，在浏览器中打开终端显示的网址。

- 输入问题，按 Enter 发送；Shift + Enter 换行。
- 点击论文名称阅读原始 PDF，勾选论文旁的方框限定问答范围；选择“全部论文”恢复全库查询。
- 首页的推荐问题绑定了具体论文，点击后会选好范围并填入问题，确认发送即可。对话中也可点击“推荐问题”继续选择。
- 每条回答下方都有“查看执行过程”，打开这一轮的流程图与 Agent Loop。处理中只显示简短状态，也可进入实时视图。
- 拖动执行时间轴，或使用播放、暂停、上一事件和下一事件，查看对应时刻的上下文、可见输出、工具参数与返回。点击流程节点可定位事件，也可在独立窗口打开。回放按工具批次组织，区分检索计划、模型决策和工具返回；上下文压缩作为独立事件展示。
- 请求详情中的 JSON 默认缩进换行，可切换查看原始文本。
- 勾选多篇后，泛指所选论文的问题会逐篇分析。回答会列出每篇的覆盖情况，原文不足时明确说明。问题中明确点名或排除论文时，以问题为准。
- 回答支持普通文本和 Markdown。部分论文暂未取得原文时，可先阅读已有结果；无法定位的引用会标出，不生成无效的原文链接。
- 回答正文会随生成逐步显示，完成后保留最终回答和引用。支持标题、列表、表格、代码及行内、独立公式；执行计时以整数秒更新。
- “记忆”展示实际保存的论文对象、回答偏好、对话摘记和来源轮次；完成回答后更新，自主选择论文的问答也会记录。
- 输入区按当前保留的对话、摘要、记忆、工具与检索结果估算会话上下文占用，自动压缩使用同一数值，在达到窗口的 70% 时触发。每次模型请求还会检查输入、回答预留空间和安全余量；必要时提前整理上下文，并按剩余空间调整回答上限。单轮回答下方另列该轮的累计调用用量。“查看与压缩”可安排下一问前整理，并查看前后用量、实际保存的摘要与历史记录。手动和自动使用相同的近期对话保留策略。
- 讲解或翻译摘要时会读取完整摘要，点击引用即可查看对应原文。目录中的摘要预览用于找论文，作答引用使用实际读取的来源。
- 点击回答中的引用编号查看原文；窄屏下会打开引用面板。
- 原文依据默认显示英文。点击“翻译为中文”后才请求译文，译文使用当前模型生成并缓存在本机；英文原文仍可随时查看。阅读翻译单独记录请求次数，每轮最多 12 次，不改变问答循环的请求上限。
- 右侧“原始 PDF”展示整篇论文，上下滑动即可连续阅读，页码随位置更新，也可用上一页/下一页快速定位。缩放时保留阅读位置。首次阅读从 arXiv 获取原文，保存在本机 `.cache/papers/`，以后可直接读取；网络不可用时可重试或打开官方原文。
- 默认开启“跟随讨论”：读取原文和生成引用时，右侧自动打开正在讨论的论文。手动选择论文或查看原文依据后，本轮保持你的选择，下一问恢复跟随；取消勾选可一直手动阅读。
- 鼠标移到回答中的引用编号，右侧会打开对应 PDF、滚动到原文所在页并高亮匹配段落。键盘聚焦引用也可定位；高亮随缩放保持对齐，可点击“清除高亮”取消。暂时无法定位的片段可点击引用查看原文依据。
- 重新启动服务后，点击“最近对话”可继续会话。
- 点击对话旁的“…”可重命名、置顶、归档或删除。置顶对话优先显示，归档对话可从列表上方的“归档”入口找回；自定义名称会一直保留。
- 删除需确认，会移除该对话及其记忆、执行记录；删除当前对话后可直接开始新对话。论文库和模型文件保留。
- 普通程序更新、切换模型或调整压缩设置后，可以打开旧对话继续追问。旧回答、阅读记忆和累计用量保留；论文库更新后，后续回答会重新确认仍可使用的原文。
- “导出对话”下载问题、最终回答和引用。

网页会话保存在 `.local/web/sessions/`，CLI 会话保存在 `.local/sessions/`。同一个浏览器保留会话列表；清除浏览器的网站数据只移除这份列表。使用“删除”可同时清理服务端对应记录。问答或原文翻译正在进行时，需等待完成后再删除。

默认每会话最多 20 轮，普通问题每轮最多 12 次模型请求。多篇比较按论文数量增加预算，先逐篇取证，再针对缺项补查，重复片段不会反复占用本轮证据窗口。可在配置文件中调整新会话的轮数，已有网页会话保留创建时的额度和已用次数；查看剩余轮数的位置在输入框上方。检索模型由同一个 worker 提供，服务同时处理一个问题。

## 自部署到服务器

网页后端需要 Node.js 和 Python 检索环境，不能仅上传静态文件来运行完整问答。当前检索安装指南面向 Windows x64；服务器应先按同样的安装步骤验证检索环境。

通过 HTTPS 反向代理提供网站，并设置网站访问口令与实际域名：

```powershell
$env:ASTERCITE_WEB_ORIGIN = 'https://research.example.com'
# ASTERCITE_WEB_TOKEN 使用你自己生成的至少 32 字符访问口令。
npm run web -- --live --host 0.0.0.0 --port 4173
```

在浏览器弹出的连接窗口中输入访问口令。模型密钥仍由服务器的 `PIPAPER_API_KEY` 提供，访问口令用于控制谁能使用这个网站。服务器的模型调用费用由部署者承担。

反向代理需保留网站域名作为 Host，并把响应等待时间设为至少配置的 `session.turn_timeout_ms`。问答流使用 NDJSON，代理应关闭该路由的响应缓冲，以便实时显示执行过程。后端端口只向代理开放。Node 服务允许同一网站来源发起请求，每个会话都有独立的访问令牌。

## 问答中的进度与停止

生成过程中，输入框右下角显示“停止生成”。点击后会取消当前轮的模型请求，并保存已经收到的文字；原会话可以继续提问。

“任务进度”入口会随执行更新，点击可查看各篇论文的原文读取、逐项说明与证据缺口。回答下方的“查看任务进度”保留这一轮的结果；“查看执行过程”则可回放实际模型请求和工具调用。

## 发布静态演示站

`web/` 包含完整静态页面与示例，可以由支持静态文件的网站平台直接托管。重新整理示例时运行：

```powershell
npm run web:build
```

静态站点提供示例回放、原文引用与部署指南；原始 PDF 的本地缓存和完整问答使用上面的 Node 服务启动。纯静态部署可通过“打开官方原文”阅读 PDF。
