GET STARTED

把工作台带到自己的电脑

网页和 CLI 使用相同的检索与问答流程。模型由你配置。

无需安装，选择示例问题即可查看多轮问答，点击引用阅读原文。

git clone https://github.com/Wahuwahuuu/AsterCite.git
cd AsterCite
npm ci --ignore-scripts
npm run web

先准备检索环境，在配置文件中填写模型服务地址和模型名称，再设置 PIPAPER_API_KEY。

npm run doctor
npm run web -- --live

打开终端显示的网址，即可自由提问。退出后再次启动，可继续已保存的会话。
