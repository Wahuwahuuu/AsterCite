把工作台带到自己的电脑

网页和 CLI 使用相同的检索与问答流程。模型由你配置。

无需安装，选择示例问题即可查看多轮问答，点击引用阅读原文。

git clone https://github.com/Wahuwahuuu/AsterCite.git
cd AsterCite
npm ci --ignore-scripts
npm run web

下载 Windows 安装版，从开始菜单启动 AsterCite。首次准备后，填写自己的模型服务地址、模型名称和密钥，浏览器会自动打开。

安装包附带论文和完整运行环境，检索在本机进行。关闭服务窗口后，再次启动可继续已保存的会话。
